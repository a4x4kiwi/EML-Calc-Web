EML Calculator

Every computation as a binary tree: eml(x,y) = exp(x) − ln(y)

How to use

Type an expression and press =. Open the EML tree panel to see the full binary tree breakdown and step-by-step working log.

Click any tree node or log row to highlight the linked entry. Double-click a node to collapse its raw EML subtree.

SHIFT / HYP

SHIFT → sin becomes sin⁻¹, cos→cos⁻¹, tan→tan⁻¹, log→10ˣ, ln→eˣ
HYP → sin→sinh, cos→cosh, tan→tanh
SHIFT+HYP → sin→sinh⁻¹, cos→cosh⁻¹, tan→tanh⁻¹

Key functions

nPr nCr permutations / combinations  ·  x! factorial  ·  EXP ×10ⁿ  ·  Ans last result  ·  ∛x cube root  ·  1/x reciprocal

About the maths

All functions are built purely from eml(x,y) = exp(x) − ln(y) — the only primitive that uses Math.exp and Math.log. π is computed via Machin's formula as a real EML tree.
